# Playlist files

Place your `.txt` playlist files here, with one song per line. Include both the
artist and song title for more reliable matching:

```text
Miles Davis — So What
John Coltrane — A Love Supreme
```

Each filename without `.txt` becomes the playlist title. Local `.txt` files are
excluded by the project's `.gitignore`.

See the [project README](../README.md) for setup and import instructions.
